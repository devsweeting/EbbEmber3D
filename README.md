<h3 align="center">Sweat. Plunge. Backflip. Repeat.</h3>

<p align="center">A tiny, hand-built 3D diorama of Portland's floating sauna on the Columbia River.</p>

<p align="center"><strong><a href="https://ebbember3d.vercel.app">Step onto the dock →</a></strong></p>

## Dive in

You'll need [Node.js](https://nodejs.org/) 18 or newer. No towel required.

```bash
npm install
```

```bash
npm run build
```

```bash
npm run serve
```

Then open **http://localhost:4180** and feel the steam.

## Things to do

- **Drag** to walk around the dock.
- **Scroll** to get a closer look.
- **Day** for bright skies and a clear look at the river.
- **Dusk** for a full-send Pacific Northwest sunset.
- **Night** for stars, glowing lights, and a crackling fire pit.
- **Open roof** to peek inside the sauna.
- **Pixel** to go retro: click once for half pixel, again for full pixel, and once more to go back.
- **Pause** to catch the backflip mid-air.
- **Reset** when you've drifted too far downriver.

Keep an eye out for the brave soul pulling the Downpour.
